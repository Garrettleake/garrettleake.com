# garrettleake.com

Personal portfolio site for Garrett Leake — static HTML on GitHub Pages.

- `index.html` — home. `work/…/`, `about/`, `contact/` — one folder per page, each with its own `index.html`.
- `styles.css` — shared styles. `img/` — photos and graphics. `media/` — the merch teaser videos.
- `404.html` — sends old or mistyped paths to the right page.
- `CNAME` — custom domain. **Do not delete or edit this file.**
